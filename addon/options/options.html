What does Reindex do?

Triggers an immediate indexing cycle outside the normal schedule. It does not wipe and rebuild the index from scratch.

  • Fetches new emails since the last cycle and adds them to the index.
  • Runs the cleanup pass that removes stale entries for emails no longer present on the server.
  • Counts against your IMAP provider's rate limits — large mailboxes (Gmail in particular) can be throttled and produce a partial cycle.
  • Bypasses any active per-account pause.
  • Cannot start while another cycle is in progress (the server returns 409).
