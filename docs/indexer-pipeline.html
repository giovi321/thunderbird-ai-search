Indexer pipeline: one cycle

Each cycle starts with a STATUS pre-pass, then runs the four-stage loop per folder. Cleanup is a separate, throttled phase that fires after the loop only when it is due.

Steps 2 to 5 run interleaved per folder, not as four sequential phases over the whole mailbox · Cycle repeats every schedule_minutes; set to 0 to index once and stop.
